# Railgun&Coin

Minecraft 1.21.1 / NeoForge 21.1.249 / Immersive Engineering 12.4.2 向けのアドオンです。

## 必要な Mod

- NeoForge 21.1.249
- Immersive Engineering 12.4.2-194
- Create 6.0.10 以降（銀のコインのプレス加工レシピに使用）

## 導入

`railgun&coin-1.0.0.jar` を、上記の依存 Mod と一緒に Minecraft の `mods` フォルダーへ入れてください。

## 内容

- Create のメカニカルプレスで銀のナゲットを加工し、「コイン」を作成可能
- コインをIE(Immersive Engineerinng)のレールガン弾として使用（1発 4,000 RF消費）
- 命中時に防具を無視する 20 ダメージと、着弾地点に威力 8 の爆発が発生
- 地面への着弾でも爆発は発生し、弾体は残らず消滅
- 1 ブロックごとに連なる専用衝撃波エフェクトと、発射時のソニックブーム音
- 半径 32 ブロック、最寄りの敵対 Mob をロックオン
- 専用カーソル・ロック音・ホーミング射撃
- コイン装填後、フルチャージ状態を 4 秒維持するとレールガンが暴発
- 初回発射時に挑戦「とある科学の…」を解除
- IE の棒系レールガン弾に +4 ダメージ、グラファイト電極に +6 ダメージ

## 開発用ビルド

Java 21 を使い、プロジェクトのルートで次を実行します。

```powershell
.\gradlew.bat build
```

生成物は `build/libs` に出力されます。
