# Railgun&Coin

Minecraft 1.21.1 / NeoForge 21.1.249 / Immersive Engineering 12.4.2 向けのアドオンです。

## 必要な Mod

- NeoForge 21.1.249
- Immersive Engineering 12.4.2-194
- Create 6.0.10 以降（コインのプレス加工レシピに使用）
- Create Crafts & Additions 1.6.0（帯電コインの充電レシピに使用）

## 導入

`railgun&coin.jar` を、上記の依存 Mod と一緒に Minecraft の `mods` フォルダーへ入れてください。

## 内容

- Create のメカニカルプレスで銀のナゲットを加工し、「コイン」を作成可能
- Create Crafts & Additions のテスラコイルの下にあるデポへコインを置くと、160,000 FEを20秒かけて消費し「帯電コイン」に変化
- コインはレールガンで1発 4,000 RFを消費し、直撃で24ダメージ、着弾地点で威力4の爆発が発生
- 帯電コインは1発 8,000 RFを消費し、防具を無視する直撃42ダメージと威力7の爆発が発生。爆風で燃えた各生物には5ダメージの雷が3本落ちる。ブロックへの着弾時は着弾点に同仕様の雷が10本落ちる。発射時に反動で17ダメージを受け、後ろへ約4ブロックノックバックする
- 地面への着弾でも爆発は発生し、弾体は残らず消滅
- 1 ブロックごとに連なる専用衝撃波エフェクトと、発射時のソニックブーム音
- 半径 32 ブロック、最寄りの敵対 Mob をロックオン
- 専用カーソル・ロック音・ホーミング射撃
- コイン装填後、フルチャージ状態を4秒維持すると威力4で暴発
- 帯電コインは暴発が通常より1秒早く、威力7で暴発
- 初回発射時に挑戦「とある科学の…」を解除
- IE の棒系レールガン弾に +4 ダメージ、グラファイト電極に +6 ダメージ

## 開発用ビルド

Java 21 を使い、プロジェクトのルートで次を実行します。

```powershell
.\gradlew.bat build
```

生成物は `build/libs/railgun&coin.jar` に出力されます。ファイル名にMODのバージョン番号は付きません。
