# Railgun Coin

Minecraft 1.21.1 / NeoForge 21.1.249 / Immersive Engineering 12.4.2 向けのアドオンです。

## 必要な Mod

- NeoForge 21.1.249
- Immersive Engineering 12.4.2-194
- Create 6.0.10 以降（銀のコインのプレス加工レシピに使用）

## 導入

`railguncoin-1.0.0.jar` を、上記の依存 Mod と一緒に Minecraft の `mods` フォルダーへ入れてください。

## 内容

- Create のメカニカルプレスで `#c:nuggets/silver` を加工し、「銀のコイン」を作成
- 銀のコインを IE のレールガン弾として使用（1発 4,000 RF）
- 命中時に防具を無視する 20 ダメージと、地形を壊さない威力 10 の炸裂
- 地面への着弾でも炸裂し、弾体は残らず消滅
- 1 ブロックごとに連なるウォーデン風の専用衝撃波エフェクトと、発射時のソニックブーム音
- 半径 32 ブロック、視界内かつ遮蔽物のない最寄りの敵対 Mob をロックオン（エンダーマンを除く）
- 専用カーソル・ロック音・ホーミング射撃
- コイン装填後、フルチャージ状態を 4 秒維持するとレールガンが暴発
- 発射時に挑戦「とある科学の…」を解除
- IE の棒系レールガン弾に +4 ダメージ、グラファイト電極に +6 ダメージ

## 開発用ビルド

Java 21 を使い、プロジェクトのルートで次を実行します。

```powershell
.\gradlew.bat build
```

生成物は `build/libs` に出力されます。
